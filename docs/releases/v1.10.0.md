# Mise v1.10.0 — 2026-11-14

Voice serving scale, shopping list, print, ringtone fix, keep awake.

- Voice serving scale: "double" / "halve" / "one and a half" / "regular" work in cook mode.
- Shopping list v1: add any recipe's non-serving ingredients to a list; toggle bought, copy, clear checked.
- Print recipe button on recipe pages: Android APK routes to the native system print dialog; desktop uses `window.print()`.
- Ringtone now audible on Android: WebView blocks autoplay on tick, so the native alarm-stream ToneGenerator plays the chosen chime; web Audio remains a desktop fallback.
- Mic disabled at timer expiry; Ready / Not ready decides how the cook continues.
- APK size budget enforced in CI: debug ≤ 4 MB, release ≤ 2 MB (superseded by the 12 MB budget in the following commit).
- versionCode 13 · web version 20
