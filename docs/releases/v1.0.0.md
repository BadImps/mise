# Mise 1.0.0

Mise is a source-attributed recipe book with a cook mode built for the kitchen. This is the first Android release, published through GitHub Releases with in-app content updates.

## Recipes

- 253 bundled records: 130 world recipes across 23 cuisines, 55 African recipes, 63 Caribbean recipes, and 5 samples.
- Africa and Caribbean collections combine TheMealDB records with publisher recipe-card data where TheMealDB has no coverage.
- Publisher wording, gaps, and attribution are preserved. Missing times, yields, or units stay missing.

## Cooking

- Cook mode shows the complete instruction text, one active step at a time.
- Inline timers and a persistent timer dock stay visible while cooking.
- The ingredient binder page keeps the handwritten ingredient names and charcoal-and-brass theme.
- Saved recipes live in local storage and survive app restarts.

## Android

- Native WebView host for phones, foldables, tablets, and Chromebook-class devices.
- Unrestricted orientation, multi-window resizing, and system-bar and cutout insets.
- Bundled web content works offline.
- Content updates install inside the app after SHA-256 verification.
- Native updates use Android `DownloadManager` and the system installer, with checksum verification before installation.

## Install

Download `mise-1.0.0.apk` below. Android will ask you to allow installs from the browser or file manager you used; Mise itself will also ask before opening the system installer for a future update.

The APK is signed with a release key. Keep the app installed if you want future releases to update in place.

## Source note

Recipe photographs from publishers are not bundled or hot-linked. TheMealDB meal photographs are used with their records. Recipe text remains attributable to its original publisher; see [assets/credits.md](https://github.com/BadImps/mise/blob/main/assets/credits.md).
