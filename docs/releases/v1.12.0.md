# Mise v1.12.0 - 2026-11-18

Kitchen export and tool-photo polish.

- Export/import the kitchen state as one JSON file (imports, pantry, favorites,
  voice preferences, shopping list). Download on desktop, paste on Android. No
  account, no server.
- Storage schema envelope (`mise.imported.v3`) with a frozen v2 rollback: reading
  a v2 record never writes it, so a bad build cannot empty a kitchen silently.
- Publisher-provided nutrition captured verbatim when present
  (publisher JSON-LD `NutritionInformation`); the nutrition panel renders only
  when the publisher supplied it.
- Deterministic unit conversion next to scaled amounts (tsp/tbsp ↔ ml, cup →
  grams for stable staples), labelled as Mise conversions, never as
  publisher-claimed values.
- Timer prompt outside voice mode: a dismissible "start a timer?" when a step
  names a duration and no timer is active.
- Shopping list: print and share buttons.
- Kitchen-tool popover photos: the seven weakest were re-sourced from Commons
  categories and the owner picked one of five options each; the popover now
  shows the whole tool, letterboxed, instead of a cropped fragment; two
  owner-supplied photographs (baking sheet, paring knife) are bundled for
  offline use and credited as not from Commons.
- Playwright offline smoke test runs in CI on every push.
- Roadmap panel unchanged.
